# 测试套件

[English](test-suite.md) · [测试方法与结果表](../README.zh-CN.md#methods)

BenchFS 将专项检查、上游文件系统测试和应用测试结合起来。各组测试分别报告成绩，读者可以在首页直接对照方法与结果。

| 测试组 | 检查内容 | 得分方式 |
|---|---|---|
| BenchFS 语义测试 | 任务规格要求的文件系统行为 | 类别平均 |
| pjdfstest | 系统调用层面的 POSIX 文件操作语义 | 类别平均 |
| xfstests | 文件操作组合、数据完整性与复杂使用场景 | 类别平均 |
| 磁盘格式 | 写出的数据是否符合规定存储格式 | 原生一致性分 |
| 稳健性 | 压力和异常条件下的行为 | 类别平均 |
| 崩溃一致性 | 意外中断后的状态处理、持久性和结构完整性 | 类别平均 |
| 真实应用 | 任务完成、数据正确性及重新打开后的行为 | 类别平均 |
| SDK smoke | 构建与基本检查 | 不计分 |

适用项数、通过率和得分取自各实现的实际测试记录，见[分项结果](../README.zh-CN.md#methods)。性能尚未测量。

## 开发反馈

Agent 在开发 VM 中可以运行一部分反馈测试。基础反馈包括 BenchFS 语义检查、pjdfstest 和 xfstests 子集；完整测试在提交实现后执行。隐藏测试检查的仍是任务规定的能力，不额外引入未说明的功能要求。

## 公开内容

本仓库说明测试目的、方法和汇总结果，不公开具体用例编号、操作序列、输入样本或预期输出。任务提供给 agent 的材料目录见 [VM 材料说明](../vm-agent/README.zh-CN.md)。
